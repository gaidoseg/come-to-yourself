## Funnel Stages
1. **Awareness** — Instagram (soon TikTok) content, see `docs/CONTENT_STRATEGY.md`
2. **Lead** — comments/follows/saves on content; DMs "READY" per the content CTA
3. **Conversation** — DM exchange to warm up and qualify before booking
4. **Free Clarity Call** — booked via Calendly (see Booking Flow below); run using the structure in `Outputs/sales/2026-10-31_dm-followup-sequence_and_clarity-call-structure.md`
5. **Close** — no formal written proposal today; the Clarity Call itself is the pitch. Enrollment details (payment, contract) handled live on/after the call.
6. **Handoff** — once closed, hands to Client Success Agent for onboarding

## Lead Sources
- Instagram organic content (primary)
- Instagram DMs directly (someone messages without going through a specific post)
- Referrals from existing clients (informal today, no structured ask yet)
