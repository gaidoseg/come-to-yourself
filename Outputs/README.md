# Outputs

Finished/drafted deliverables, one subfolder per agent so it's clear who produced what and where to find it.

- `content/` — social posts, captions, scripts, newsletters (Content Agent)
- `marketing/` — campaign plans, ad copy, email sequences (Marketing Agent)
- `sales/` — DM/email scripts, proposals, follow-up sequences (Sales Agent)
- `client-success/` — onboarding docs, session prep, testimonial requests (Client Success Agent)
- `website/` — published pages, landing pages, deploy notes (Deploy Agent)

Everything here is a **draft until Emilie approves it** — agents don't post, send, or publish on their own.
