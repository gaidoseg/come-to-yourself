# Part 1 — TikTok Test-Launch Plan

**Why now:** TikTok was approved 2026-10-31 in `docs/MARKETING_CHANNELS.md` as a second channel to test, based on research showing a large, active "nervous system regulation" audience there (~178K videos on one hashtag — see `Reference/research/icp-and-content-trends-2026.md`). It is not active yet. This is a plan to run a bounded test, not a commitment to TikTok long-term.

**Constraints going in:** No analytics tool is connected to either Instagram or TikTok (per `docs/MARKETING_CHANNELS.md`). All measurement below is manual — reading numbers off the native app and logging them by hand. No booking tool exists, so the TikTok CTA has to route the same place Instagram's does: a DM / bio link to the free Clarity Call, not a direct booking link.

## What to post

Per `docs/CONTENT_STRATEGY.md`, the repurposing workflow is: one raw Reel → posted as-is on TikTok (same raw, low-production talking-head style works on both platforms) → key line later pulled into an Instagram carousel/caption. This test should follow that, not create a parallel TikTok-only content stream — Emilie doesn't have bandwidth for two original pipelines, and the research found raw/unpolished content is exactly what's outperforming on both platforms right now.

- **Reuse as-is:** The 5 scripts in `Outputs/content/2026-10-31-reels-batch-01.md` were already written and flagged by the Content Agent as reusable on TikTok without changes (same talking-head format, same hooks). Once Emilie approves and films them for Instagram, post the same files to TikTok — same hook, same on-screen text, same CTA logic (DM "READY").
- **One TikTok-native addition per week (optional, if time allows):** the research notes TikTok's nervous-system content is often *demonstrative* — creators showing a somatic regulation technique on camera in real time (e.g., "shaking out" tension, a vagus-nerve exercise), not just talking. This is a format worth testing natively on TikTok since it's less established in Emilie's current Instagram batch. Keep it in the same raw, no-edit style — not a production lift.
- **Do not** write TikTok-specific scripts from scratch for this test. The point is to find out cheaply whether the repurposed content performs there before investing more.

## Cadence

Per `docs/CONTENT_STRATEGY.md`: start light, 2–3x/week. For a 2–4 week test:

- **Weeks 1–2:** Post 2–3x/week, all repurposed Instagram Reels (whatever's already filmed/approved that week). No new production burden — this rides on the existing weekly content batch.
- **Weeks 3–4 (if continuing):** Hold the same cadence; slot in 1 demonstrative/somatic clip if Emilie wants to test the native format. Otherwise keep repurposing.

This keeps the test cheap: it adds "also post this to TikTok" to an existing workflow rather than a second content job.

## What to measure (manually — no analytics tool connected)

Since nothing is wired up to pull numbers automatically, this needs a simple manual log — a running note (spreadsheet or even a page in this repo) checked weekly, recording per video:

- **Views**
- **Saves**
- **Shares** (TikTok surfaces this prominently; worth tracking since it's a strong distribution signal there)
- **Follower count** (start-of-test vs. end-of-test delta on the account)
- **DMs/comments that look like genuine interest** (asking what the program is, asking to work together, mentioning "READY") — a manual, judgment-based count since there's no CRM to tag or track lead source automatically

Be honest with Emilie up front: without an analytics tool, this is a hand-counted log, not a dashboard. Comparing TikTok numbers to Instagram's will be rough (different manual tracking habits, no unified source of truth) — treat Week 1–4 numbers as directional, not precise.

## Decision point at the end of the test (2–4 weeks)

At the end of the window, review the manual log and decide one of three things:

1. **Continue** — some combination of views/saves/shares/DMs suggests real traction worth sustaining at the current light cadence (2-3x/week, repurposed content). No new tooling or investment needed to keep doing this.
2. **Drop** — negligible engagement and no inbound interest after a fair test (full 2–4 weeks, full repurposed batch posted). Stop posting to TikTok; redirect that time back to Instagram-only.
3. **Scale** — strong enough signal (noticeably higher reach/saves/shares than Instagram, and/or real DM interest) to justify investing in TikTok-native content (the demonstrative/somatic format, more frequent posting) rather than pure repurposing. This would be a new, larger decision — not something this test plan pre-commits to.

This decision is Emilie's to make from the manual log — the Marketing Agent isn't setting a numeric bar (e.g., "X views = continue") because there's no historical baseline yet to calibrate against, and inventing one would be a made-up metric.

## Prerequisites / things this plan assumes

- Emilie has (or creates) a TikTok business/creator account under the same handle pattern as Instagram (@emiliegaidos or closest available).
- The Content Agent's batch gets filmed and approved on the normal weekly cycle — this plan doesn't add extra content production, only extra posting.
- No ad spend, no analytics tool, and no booking tool are assumed to exist for this test — if any of those get added later, this plan should be revisited.

# Part 2 — Funnel Tradeoff Memo: Should There Be a Mid-Ticket Step?

**This is not a recommendation.** This lays out the open question research surfaced (`Reference/competitors/subconscious-reprogramming-coaches-2026.md`) so Emilie can decide. The Marketing Agent is not adding or pricing a mid-ticket offer here.

## The current funnel

Free content (Instagram, soon TikTok) → free Clarity Call (discovery call) → "Come Home to Yourself," the one 6-month 1:1 program (`docs/OFFERS.md`). There is no step in between. There is also no price set yet for the 1:1 program, and no email list/CRM, so there's no automated nurture sequence either — everything between "saw a Reel" and "booked a call" currently happens through organic content and Instagram DMs.

## What competitors do differently

Several researched competitors insert a lower-ticket offer before their full 1:1 container:

- **The Exhale Collective** (Lovisa Engstrand) — a ~$20 CAD masterclass and a "Calm & Resilient" course sit ahead of her 1:1 coaching.
- **Natasha Levinger** — a ~$333 group "Inner Child Healing" class, plus async voice-note/email support tiers, sit ahead of her full 1:1 mentorship.
- **Ludovica Colella** — not a mid-ticket product exactly, but a pay-per-session model (£150–165/session, packages of 10 or 20) that lets a client enter at a much lower commitment than a fixed 6-month container.

None of these is a confirmed like-for-like match to Emilie's exact offer (see the competitor file's "what's still unknown" section — full 1:1 pricing for most of them isn't public), so treat this as a structural pattern worth noticing, not proof that it's the better model.

## The tradeoff

**Arguments for adding a mid-ticket step:**
- Lowers the commitment required to say "yes" to something — a free call straight into a 6-month container (once priced) is a large jump with nothing in between to build trust or prove the method works for this specific person.
- Could generate some revenue from leads who aren't ready for a full 6-month commitment yet, rather than losing them entirely.
- Gives Emilie a lower-stakes way to demonstrate the subconscious-reprogramming approach works before someone commits to the full container — which may make the free Clarity Call convert better, since the person arrives already having felt a result.
- Produces a natural qualification signal: someone who buys and engages with a mid-ticket offer has already self-selected as a more serious lead than someone who only follows the content.
- Emilie already has Kajabi (used to deliver the 12-module 1:1 curriculum per `docs/OFFERS.md`), so there's at least a plausible existing platform to host a course/masterclass on — this wouldn't necessarily mean adopting a brand-new tool, though it hasn't been confirmed Kajabi is set up for a separate standalone product today.

**Arguments for keeping the funnel simple (no mid-ticket step):**
- Emilie is a solo operator with no email/CRM tool, no paid ads, and no confirmed price even for the flagship 1:1 offer yet (`docs/OFFERS.md`, `docs/MARKETING_CHANNELS.md`). Adding a second product means building, pricing, marketing, and fulfilling two offers instead of one, with no automation to support the handoff between them.
- A mid-ticket product needs its own content/sales copy, its own delivery (even if "just" a Kajabi course), and its own nurture path from purchaser → Clarity Call lead — all manual today given no CRM exists to automate that sequence.
- Could dilute the premium positioning: Emilie's brand voice (`docs/BRAND.md`) leans into a deep, structured, 6-month transformation, not a quick-win product. A $20–300 course sitting in front of it risks signaling "this is a content business with an upsell" rather than "this is a focused, premium 1:1 container."
- The free Clarity Call already exists as a zero-cost trust-building step (a real conversation, not a sales page) — it's possible the gap competitors are filling with a paid mid-ticket product, Emilie is already filling for free via the call itself.
- Every dollar/hour spent building a new offer is a dollar/hour not spent on the one thing that currently drives revenue (the 1:1 program) while its own price isn't even set yet — sequencing risk: pricing and proving the flagship offer arguably comes before adding a second one.

## What this needs before it can even be evaluated properly

Regardless of which way Emilie leans, a few open items would need resolving first:
- The 6-month 1:1 program needs a confirmed price (`docs/OFFERS.md` currently has none) — it's hard to judge whether a mid-ticket step is needed without knowing the gap it would need to bridge.
- If a mid-ticket offer were ever built, it would need its own entry in `docs/OFFERS.md` and its own funnel note in `docs/MARKETING_CHANNELS.md` — not assumed into existence here.
- No tool currently exists to automate a sequence between "bought mid-ticket thing" and "booked Clarity Call" — that handoff would be manual (DM/email by hand) unless/until a CRM is in place.

**Bottom line:** this is Emilie's call, not a Marketing Agent decision. Flagging it clearly so it isn't lost, consistent with what the research file recommended.
